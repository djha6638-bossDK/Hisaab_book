# hisaab_book

personal finance Ledger App

## Daily Attendance

- App khulte hi daily attendance gate aata hai, jab tak us din ki attendance save na ho jaye.
- `Skip` sirf current screen close karta hai, day ko handled mark nahi karta.
- Same day app dubara kholne par attendance page phir se aata hai.
- `Save attendance` us din ko handled mark karta hai, isliye same day baad me home open hota hai.
- Attendance screen me `Present` aur `Absent` style ke large buttons use hote hain taaki state immediately clear dikhe.

## In-app updates

- App public GitHub releases (`djha6638-bossDK/Hisaab_book`) se naya version check karta hai.
- Naya version milne par Home screen par update card aata hai; APK app me download hota hai aur Android installer khulta hai.
- Release publish karne ke liye `scripts/release.ps1` chalao. Detail: `docs/android_release.md`.
